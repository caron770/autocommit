## 🚀 快速开始

### 1. 环境准备

#### Windows系统
```bash
# 双击运行启动脚本
scripts\start_ui.bat
```

#### Mac/Linux系统
```bash
# 运行启动脚本
./scripts/start_ui.sh
```

#### 手动安装
```bash
# 安装依赖
pip install -r requirements.txt

# 安装Playwright浏览器
playwright install chromium

# 启动程序
python main.py
```

### 2. 首次运行

1. 双击运行 `main.py` 或使用启动脚本
2. 程序会自动打开图形界面
3. 按照界面提示配置参数
4. 点击"启动机器人"开始运行

## 📖 使用教程

### 基础使用流程

#### 步骤1: 选择运行方法
1. 在"运行方法"下拉框选择方式
2. 新手推荐选择"Playwright"
3. 如需后台运行，勾选"无头模式"

#### 步骤2: 配置账号（可选）
1. 输入淘宝用户名
2. 输入密码
3. 如果不登录，某些功能可能受限

#### 步骤3: 设置直播间
1. 复制淘宝直播间URL
2. 粘贴到"直播间URL"输入框
3. 确保URL格式正确

#### 步骤4: 配置评论内容
1. 在文本框中输入评论内容
2. 每行一条评论
3. 可以输入任意多条
4. 设置发送间隔（建议5-12秒）

#### 步骤5: 启动机器人
1. 点击"▶️ 启动机器人"按钮
2. 观察右侧日志输出
3. 查看统计信息
4. 需要停止时点击"⏹️ 停止机器人"

### 高级功能使用

#### 智能回复设置

智能回复会根据用户评论中的关键词自动回复：

| 关键词 | 自动回复内容 |
|--------|-------------|
| 价格/多少钱 | "价格很实惠哦！"等 |
| 质量/怎么样 | "质量绝对保证！"等 |
| 发货/快递 | "发货很快的！"等 |
| 尺寸/大小 | "有详细尺寸表的！"等 |
| 颜色 | "有多种颜色可选！"等 |
| 优惠/便宜 | "现在有活动！"等 |

#### 配置保存与加载

**保存配置：**
1. 点击"💾 保存配置"按钮
2. 选择保存位置
3. 输入文件名（如 my_config.json）
4. 点击保存

**加载配置：**
1. 点击"📂 加载配置"按钮
2. 选择之前保存的配置文件
3. 所有设置会自动填充

#### 日志管理

**清空日志：**
- 点击"🗑️ 清空日志"按钮
- 日志显示区域会被清空

**导出日志：**
- 点击"💾 导出日志"按钮
- 选择保存位置
- 日志会保存为txt文件

## ❓ 常见问题

### Q1: 启动后提示缺少模块怎么办？

**A:** 运行安装命令：
```bash
pip install -r requirements.txt
playwright install chromium
```

### Q2: 无法连接到直播间？

**A:** 检查以下几点：
1. 直播间URL是否正确
2. 直播是否正在进行
3. 网络连接是否正常
4. 尝试手动访问直播间确认

### Q3: 评论发送失败？

**A:** 可能的原因：
1. 未登录或登录状态失效
2. 评论频率过高被限制
3. 评论内容包含敏感词
4. 直播间已关闭评论功能

**解决方案：**
- 重新登录账号
- 降低发送频率（增加间隔时间）
- 更换评论内容
- 检查直播间设置

### Q4: 如何提高发送成功率？

**A:** 建议配置：
1. 使用Playwright方法
2. 发送间隔设置为 5-15秒
3. 评论内容多样化（至少10条以上）
4. 启用智能回复和礼物感谢
5. 避免重复发送相同内容

### Q5: 程序运行一段时间后卡住？

**A:** 可能原因：
1. 网络不稳定
2. 浏览器内存占用过高
3. 直播间页面出现异常

**解决方案：**
- 重启程序
- 使用无头模式减少资源占用
- 定期重启浏览器（每30分钟一次）

### Q6: 智能回复不生效？

**A:** 检查：
1. 是否勾选了"启用智能回复"
2. 方法选择是否支持（Playwright支持最好）
3. 查看日志是否有错误提示
4. 直播间是否有新评论触发

### Q7: 如何设置最优的发送频率？

**A:** 推荐设置：

| 场景 | 最小间隔 | 最大间隔 | 说明 |
|------|---------|---------|------|
| 新手测试 | 10秒 | 20秒 | 安全稳定 |
| 日常使用 | 5秒 | 12秒 | 平衡性能 |
| 高频模式 | 3秒 | 8秒 | 需谨慎使用 |

### Q8: 可以同时运行多个直播间吗？

**A:** 可以，但需要注意：
1. 打开多个程序实例
2. 每个实例配置不同的直播间
3. 建议使用不同的账号
4. 注意电脑资源消耗

### Q9: 密码安全吗？

**A:** 
- 密码仅在本地使用，不会上传
- 建议使用测试账号
- 不要在公共电脑上保存配置
- 定期更换密码

### Q10: 被检测到是机器人怎么办？

**A:** 降低检测风险：
1. 降低发送频率
2. 增加评论内容多样性
3. 使用真实的用户代理
4. 启用随机延迟
5. 避免24小时不间断运行

## 🎯 使用建议

### 最佳实践

1. **频率控制**
   - 新账号：10-20秒/条
   - 老账号：5-12秒/条
   - 高峰期适当降低频率

2. **内容准备**
   - 准备20条以上不同的评论
   - 内容要真实自然
   - 避免敏感词汇
   - 与直播内容相关

3. **运行时间**
   - 不要24小时不间断运行
   - 建议运行30分钟休息10分钟
   - 分时段运行效果更好

4. **账号安全**
   - 使用测试账号
   - 定期更换IP
   - 避免多账号同IP
   - 注意平台规则

### 性能优化

1. **提高响应速度**
   - 使用WebSocket方法
   - 启用无头模式
   - 关闭不必要的功能

2. **降低资源消耗**
   - 使用无头模式
   - 定期清理日志
   - 减少监控频率

3. **提高稳定性**
   - 使用Playwright方法
   - 设置合理的超时时间
   - 启用异常重试
